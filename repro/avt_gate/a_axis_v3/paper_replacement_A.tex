\paragraph{Audio evidence gate.}
The audio gate decides each event separately, from that event's own initial audio judgment and its own tool evidence.
For a sounding event, FLAM opens the gate only in the direction that can change the initial judgment: an initially passing event opens when its FLAM score is below the calibrated FAIL threshold, and an initially failing event opens when its score reaches the calibrated PASS threshold (both thresholds are selected on P01/P02 for each admission limit $\alpha$).
P01/P02 contains no speech, so speech events use a fixed rule that is the same for every $\alpha$ and is not calibrated: the gate opens only when the event was initially judged as failing and Whisper recognises that event's own requested word (exact token match in segments with no-speech probability below 0.5).
An initially passing speech event is never reopened, a word requested by another event never opens it, and a FLAM score never opens a speech event.
Missing tool output keeps the gate closed.
AVT-Judge reconsiders only the opened events, in one text-only call per clip that contains the Whisper transcript (if a speech event opened) and the FLAM lines of the opened sounding events; every closed event keeps its initial label, and an opened event keeps its initial label if the Judge sees no reason to revise it.
Gate-only uses the same openings and applies the admitted direction directly (an opened speech event becomes PASS).
